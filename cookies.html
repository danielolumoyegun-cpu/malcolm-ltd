Cookie Policy

Last updated: 26 October 2026

The short version

This website does not set any cookies. We do not use analytics, advertising pixels or any other tracking technology, and nothing is stored on your device to identify you or follow you between visits. That is why you are not asked to accept cookies when you arrive.

What happens instead

Two things still involve another company's servers when you load a page, because of how the site is built. Neither places a cookie, but both can see your IP address, in the same way any website you visit can.

Google Fonts
The typefaces on this site are requested from Google's font servers as each page loads. Google receives your IP address and basic browser information as part of that request.
GitHub Pages
This site is hosted on GitHub Pages. Like any web host, GitHub keeps standard server logs that include IP addresses, for security and to keep the service running.

If you submit an enquiry form, the information you type is passed to Web3Forms, which delivers it to our inbox. That happens only when you choose to submit a form.

Controlling this

Because no cookies are set, there is nothing to turn off on this site. You can still block third-party requests or clear site data using your browser's privacy settings, and the site will continue to work — the text may simply appear in a different typeface.

If this changes

If we add analytics or any other technology that uses cookies, we will update this page and ask for your consent before anything non-essential is set.

Questions about this policy can go to info@malcominc.co.uk. See also our Privacy Policy.

Keep this accurate This page is true of the site as built today. If analytics, a chat widget, embedded video or advertising pixels are added later, this page needs updating and a consent banner will almost certainly be required. Remove this note before launch.
